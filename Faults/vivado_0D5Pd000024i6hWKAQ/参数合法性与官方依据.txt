参数合法性与官方依据

公开依据为 AMD PG210 5.1（当前网页标注 2026-07-08）。核对日期：2026-11-06。
下文“安装版定义”的数值边界和枚举来自 Vivado 2026.1 安装文件 data/ip/xilinx/xxv_ethernet_v5_1/component.xml 与 ptp_1588_timer_syncer_v2_0/component.xml。
本例配置组合经 Vivado 原生参数校验、官方示例生成和 XSim 行为仿真核对。

使用范围与配套条件

PTP 安装版 changelog 的 2021.2 条目要求由 Ethernet 父 IP 配置使用，不支持独立使用。本工程由 xxv_ethernet 官方 Open IP Example Design 流程生成 PTP，保留完整父 IP 示例连接。
采用 MAC+PCS/PMA 64-bit、BASE-R、单核、AXI4-Lite 和用户 FIFO；时间戳开启，模式使用工具支持的 One Step 或 Two Step。未启用 BASE-R 不支持的 FEC。
GT_LOCATION 与 INCLUDE_SHARED_LOGIC 一致；统计资源类型仅在统计计数器开启时定制。
PTP 的 AXI4LITE_FREQ 与 GT_DRP_CLK 一致，TS_CLK_PERIOD 等于 SYS_CLK/1000；64 位 10G 和 25G 对应 RESYNC_CLK_PERIOD 分别为 6400 ps 和 2560 ps。
PTP 的 Timer_Syncer、Time_of_Day、CORE_CONFIGURATION=1、端口数及高精度模式等由官方示例生成，符合 PG210 Software Driver Initialization 的 XXV 配置示例。
