一、公开资料与取值依据

公开依据为 AMD PG119 v12.0；本次访问的官方页面标注发布日期为 2021-02-04。
核查日期：2026-10-17。文档发布日期与安装版 IP 修订号分别记录。
本例使用 Vivado 2026.1 随附的 Accumulator 12.0 Rev.22；IP 状态为 Up-to-date。
官方手册：https://docs.amd.com/v/u/en-US/pg119-c-accum
官方 PDF：https://docs.amd.com/api/khub/documents/ybLL33kjyUtDPZcUK98Igg/content
下列链接的 page 数字为 PDF 页码；也可按参数名或章节名定位。

以下逐项对应工程明确设置的 16 个 IP 参数，已与保存的 XCI、Vivado 回读和生成的模型参数核对。
公开手册未列出完整数值范围的，补充依据为 AMD 随 Vivado 2026.1 交付的：
data/ip/xilinx/c_accum_v12_0/component.xml
该路径相对于 Vivado 安装目录。下面明确区分手册定义与安装文件中的范围、枚举，不把安装文件内容说成网页原文。
另由当前安装版完成参数设置和仿真目标生成，核对生成值没有偏离本例配置。

二、逐项参数说明

CONFIG.Implementation = Fabric
作用：选择实现资源。
官方要求与本例说明：PG119 列出 Fabric 与 DSP Slice。本例使用 Fabric，允许同步置位、同步初始化和反馈缩放等 Fabric 功能。
官方链接：https://docs.amd.com/api/khub/documents/ybLL33kjyUtDPZcUK98Igg/content#page=12

CONFIG.Input_Type = Signed
作用：选择输入 B 的符号类型。
官方要求与本例说明：PG119 允许 Signed 或 Unsigned。Signed 使用补码；本例的信号显示和参考模型按相同类型解释输入。
官方链接：https://docs.amd.com/api/khub/documents/ybLL33kjyUtDPZcUK98Igg/content#page=12

CONFIG.Input_Width = 16
作用：设置输入 B 的位宽。
官方要求与本例说明：PG119 定义该参数的用途；安装版 component.xml 规定 2–256。本例 16 位在范围内。
官方链接：https://docs.amd.com/api/khub/documents/ybLL33kjyUtDPZcUK98Igg/content#page=12

CONFIG.Output_Width = 32
作用：设置输出及累加状态的位宽。
官方要求与本例说明：PG119 第 4 页说明 Fabric 输出最高 256 位；安装版 component.xml 的静态范围为 1–258。本例取 32，未超出手册描述的 256 位，且输出宽度不小于输入宽度。
官方链接：https://docs.amd.com/api/khub/documents/ybLL33kjyUtDPZcUK98Igg/content#page=4

CONFIG.Accum_Mode = Subtract
作用：选择加法、减法或运行时加减模式。
官方要求与本例说明：PG119 定义三种累加模式；安装版枚举为 Add、Subtract、Add_Subtract。只有 Add_Subtract 配置具有 ADD 端口，ADD=1 加法、ADD=0 减法。
官方链接：https://docs.amd.com/api/khub/documents/ybLL33kjyUtDPZcUK98Igg/content#page=12

CONFIG.Latency_Configuration = Manual
作用：允许手动选择流水级数。
官方要求与本例说明：PG119 定义 Automatic 和 Manual。本例选择 Manual，配合下面的 Latency。
官方链接：https://docs.amd.com/api/khub/documents/ybLL33kjyUtDPZcUK98Igg/content#page=13

CONFIG.Latency = 1
作用：设置输入操作对应的时钟延迟。
官方要求与本例说明：安装版 component.xml 的范围为 1–2；本例为 1。PG119 第 9 页明确 Latency=1 时只有输出寄存器，因此参考模型在本次上升沿计算并在 2 ns 后比较。
官方链接：https://docs.amd.com/api/khub/documents/ybLL33kjyUtDPZcUK98Igg/content#page=9

CONFIG.Scale = 0
作用：设置反馈路径丢弃的低位数。
官方要求与本例说明：PG119 说明缩放用于 Fabric 反馈路径；安装版枚举为 0–8。本例取 0，实现方式为 Fabric。取 0 表示不丢弃反馈低位。
官方链接：https://docs.amd.com/api/khub/documents/ybLL33kjyUtDPZcUK98Igg/content#page=12

CONFIG.CE = true
作用：生成高有效时钟使能端口。
官方要求与本例说明：安装版允许 true/false；本例为 true。PG119 第 9 页 Clocking 规定 CE 关闭时暂停核心处理。
官方链接：https://docs.amd.com/api/khub/documents/ybLL33kjyUtDPZcUK98Igg/content#page=9

CONFIG.C_In = false
作用：选择是否生成进位输入 C_IN。
官方要求与本例说明：PG119 定义同步进位输入；安装版允许 true/false。本例不生成 C_IN，也不连接不存在的端口。
官方链接：https://docs.amd.com/api/khub/documents/ybLL33kjyUtDPZcUK98Igg/content#page=12

CONFIG.SCLR = false
作用：选择同步清零端口。
官方要求与本例说明：安装版允许 true/false。本例不生成 SCLR。 SINIT 若开启则不能同时开启 SCLR 或 SSET；本例满足互斥要求。
官方链接：https://docs.amd.com/api/khub/documents/ybLL33kjyUtDPZcUK98Igg/content#page=12

CONFIG.SSET = true
作用：选择同步置位端口。
官方要求与本例说明：PG119 规定 SSET 仅用于 Fabric，安装版允许 true/false。本例开启 SSET，且未开启 SINIT。
官方链接：https://docs.amd.com/api/khub/documents/ybLL33kjyUtDPZcUK98Igg/content#page=12

CONFIG.SINIT = false
作用：选择同步初始化端口。
官方要求与本例说明：PG119 规定 SINIT 仅用于 Fabric，并与 SCLR、SSET 互斥。本例关闭 SINIT。
官方链接：https://docs.amd.com/api/khub/documents/ybLL33kjyUtDPZcUK98Igg/content#page=12

CONFIG.Bypass = true
作用：生成旁路装入端口 BYPASS。
官方要求与本例说明：PG119 定义旁路装入 B 的功能，安装版允许 true/false；本例为 true。
官方链接：https://docs.amd.com/api/khub/documents/ybLL33kjyUtDPZcUK98Igg/content#page=12

CONFIG.Bypass_Sense = Active_Low
作用：设置 BYPASS 的有效极性。
官方要求与本例说明：PG119 允许高有效或低有效；安装版枚举为 Active_High、Active_Low。本例 BYPASS=0 表示旁路有效，BYPASS=1 表示普通运算。
官方链接：https://docs.amd.com/api/khub/documents/ybLL33kjyUtDPZcUK98Igg/content#page=12

CONFIG.Sync_CE_Priority = CE_Overrides_Sync
作用：设置同步控制与 CE 的优先关系。
官方要求与本例说明：PG119 定义 Sync_Overrides_CE 和 CE_Overrides_Sync，分别表示同步控制可覆盖 CE、或同步控制需 CE 有效。目标暂停观测时所有同步控制均为 0，不涉及同步清零／置位／初始化与 CE 同时有效的情况。
官方链接：https://docs.amd.com/api/khub/documents/ybLL33kjyUtDPZcUK98Igg/content#page=13

三、组合条件及测试操作合法性

本例为 Fabric 实现，输入宽度 16，输出宽度 32；输入类型为 Signed。
所选宽度处于安装版参数范围内，输出未超出 PG119 描述的 256 位 Fabric 范围。
本例使用简单整数，不涉及数值溢出或主动截短输入。
SINIT 若开启，SCLR 和 SSET 均关闭；同步置位及初始化端口均未在 DSP 实现中使用。
Scale=0 属于安装版枚举，且使用允许反馈缩放的 Fabric 实现。
手动 Latency=1 是允许值；PG119 明确该配置仅有输出寄存器，无需等待额外输入流水级。
https://docs.amd.com/api/khub/documents/ybLL33kjyUtDPZcUK98Igg/content#page=9
https://docs.amd.com/api/khub/documents/ybLL33kjyUtDPZcUK98Igg/content#page=12

CE 端口已生成，旁路极性与 XCI 及生成参数 C_BYPASS_LOW 一致。
目标操作前已经用 CE=1 的旁路装入核对该极性，并用普通运算核对符号、加减及缩放解释。
普通暂停对照中 CE=0、旁路无效，输出保持；目标操作中 CE 仍为 0，旁路有效。
所有同步控制在目标拍均为 0，因此不涉及其与 CE 的优先级冲突。
输入在下降沿改变，在下一上升沿前保持稳定；上升沿后 2 ns 再比较，避开仿真调度的瞬时更新。

四、验证方法的适用范围

预期由模型的上一状态和输入运算得出；暂停时使用状态保持规则，不依赖 DUT 的输出生成答案。
可用案例介绍中的简单整数运算及 Q_next=Q_previous 独立复核。
模型按照本例已配置的输入位宽、输出位宽、符号、极性和同步控制工作，仅用于 Latency=1。
本例没有修改官方生成的 HDL，也没有 force DUT 信号；实际输出 Q 只用于比较和显示。
时钟、激励、等待周期、模型变量及波形脚本属于测试环境设置，不是 IP 配置参数。
